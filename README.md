# 🤖 Computing Historian Agent

A conversational AI agent built with **Microsoft Foundry** that answers questions about the history of computing — significant people, events, and notable vintage computers.

Built as part of the [Develop your first agent with Microsoft Foundry](https://microsoftlearning.github.io/mslearn-agent-quickstart/) lab series on Microsoft Learn.

The agent is powered by `gpt-4.1-mini`, uses web search to provide up-to-date information, and is served through a Python Flask web application using the OpenAI Responses API.
